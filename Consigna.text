📝 Trabajo Práctico: Desarrollo de API RESTful con CRUD y Capa de Servicios
🎯 Objetivo General
Desarrollar un API RESTful robusta y modular utilizando Node.js, Express y MongoDB (Mongoose). El proyecto debe implementar las operaciones CRUD (Crear, Leer, Actualizar, Eliminar) y aplicar el patrón de separación de responsabilidades, delegando la lógica de negocio a una Capa de Servicios.
🛠️ Requisitos Funcionales y Técnicos
1. Entidades y Modelado
Entidad
Campos Clave
Requisitos CRUD
Productos
Nombre, Descripción, Precio, Stock, Categoría (Referencia)
Implementar todas las operaciones CRUD.
Categorías
Nombre, Descripción
Implementar todas las operaciones CRUD.
Usuarios
Nombre/Email, Contraseña
Opcional: Requerido para la autenticación.

2. Estructura y Lógica de Negocio (Separación de Responsabilidades)
Capa de Servicios (Obligatoria): Toda la lógica de negocio, manipulación de datos y llamadas directas a Mongoose/MongoDB deben residir en la carpeta services/.
Controladores: Los controladores (controllers/) deben ser ligeros. Su única función es manejar la solicitud HTTP (Request), delegar la lógica al Servicio correspondiente y gestionar la respuesta HTTP (Response).
Relaciones: La entidad Producto debe hacer referencia a Categoría. Utilice populate en las operaciones de lectura de productos para incluir los datos completos de la categoría.
Manejo de Respuestas: Asegurar que los Controladores y Servicios manejen adecuadamente los mensajes de estado y códigos HTTP apropiados (ej. 200, 201, 400, 404, 500) y las excepciones (try/catch).
3. Seguridad y Configuración
Encriptación: Utilizar bcrypt para hashear las contraseñas de los usuarios antes de guardarlas (mediante un pre-save hook de Mongoose).
Autenticación con JWT (Opcional):
Implementar una ruta de inicio de sesión que genere un JSON Web Token (JWT).
Crear un middleware para verificar el JWT y proteger rutas sensibles (Creación, Actualización y Eliminación).
Variables de Entorno: Usar dotenv para gestionar variables de configuración sensibles (URI de MongoDB, clave secreta de JWT).
CORS: Habilitar el middleware CORS en la aplicación principal (app.js).

El proyecto debe mantener esta estructura para garantizar la separación de la arquitectura:
proyecto-crud-mongodb/
├── app.js / index.js (Punto de entrada)
├── .env

└── src/
